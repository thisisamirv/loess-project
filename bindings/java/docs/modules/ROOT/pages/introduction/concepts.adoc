= Concepts


Understanding how LOESS works and when to use it.

== What is LOESS?

*LOESS* (Locally Estimated Scatterplot Smoothing) is a nonparametric regression method that fits smooth curves through scatter plots without assuming a global functional form.

Unlike parametric methods (linear regression, polynomial fitting), LOESS adapts locally to the data structure, making it ideal for:

* *Exploratory data analysis* — Discover patterns without assumptions
* *Trend estimation* — Extract signals from noisy time series
* *Baseline correction* — Remove systematic effects in spectroscopy
* *Genomic smoothing* — Smooth methylation, ChIP-seq, or expression data

'''

== How It Works

image::loess_concept.svg[LOESS Smoothing Concept]

_LOESS fits local weighted regressions at each point, using a focused local window around each evaluation point_

For each point in your data, LOESS:

. *Selects neighbors* — Choose the nearest points (controlled by `fraction`)
. *Assigns weights* — Closer points get higher weights (using a kernel function)
. *Fits locally* — Perform weighted least squares regression
. *Extracts value* — Use the fitted value as the smoothed estimate
. *Iterates* (optional) — Reweight points based on residuals to reduce outlier influence

'''

== The Fraction Parameter

`fraction` (also called bandwidth or span) is the most important parameter. It controls what proportion of data is used for each local fit.

[cols="1,1,1",options="header"]
|===
|Fraction |Effect |When to Use

|*0.1–0.3* |Fine detail, follows data closely |Rapidly changing signals
|*0.3–0.5* |Balanced smoothing |Most applications
|*0.5–0.7* |Heavy smoothing |Noisy data, trend extraction
|*0.7–1.0* |Very smooth |Strong noise, global trends
|===

image::fraction_comparison.svg[Fraction Effect]

_Small fraction vs large fraction — bandwidth controls how closely the fit follows local structure_

[NOTE]
====
*Rule of Thumb:* Start with `fraction = 0.67` (the default) and adjust based on visual inspection. Use cross-validation for automated selection.
====

'''

== Robustness Iterations

Standard LOESS is sensitive to outliers. *Robustness iterations* downweight points with large residuals:

[cols="1,1,1",options="header"]
|===
|Iterations |Effect |When to Use

|*0* |No robustness (fastest) |Clean data, speed-critical
|*1–3* |Moderate robustness |Most applications
|*4–6* |Strong robustness |Data with outliers
|*7+* |Very strong |Heavy contamination
|===

image::robust_iter_comparison.svg[Robustness Effect]

_Non-robust LOESS (iterations=0) vs robust LOESS — outlier influence is suppressed through iterative reweighting_

'''

== Confidence vs Prediction Intervals

image::intervals_comparison.svg[Intervals]

_Confidence intervals (narrow, mean curve uncertainty) vs Prediction intervals (wide, new-point uncertainty)_

[cols="1,1,1",options="header"]
|===
|Interval Type |What It Represents |Width

|*Confidence* |Uncertainty in the _mean curve_ |Narrow
|*Prediction* |Uncertainty for _new observations_ |Wide
|===

* Use *confidence intervals* to show where the true trend likely lies
* Use *prediction intervals* to show where new data points might fall

'''

== Execution Modes

Choose the right mode based on your use case:

[cols="1,1,1,1",options="header"]
|===
|Mode |Use Case |Memory |Features

|*`Loess`* (batch) |Complete datasets |Entire dataset |All features
|*`StreamingLoess`* |Large files (>100K points) |One chunk |Residuals, robustness
|*`OnlineLoess`* |Real-time data |Fixed window |Incremental updates
|===

'''

== Quick Decision Guide

[cols="1,1",options="header"]
|===
|Situation |Mode

|Data fits in memory; needs intervals or CV |`Loess`
|Data too large for memory or arrives in chunks |`StreamingLoess`
|Data arrives point-by-point in real time |`OnlineLoess`
|===

See xref:../guide/adapter-choice.adoc[Execution Modes] for a fuller comparison.

'''
