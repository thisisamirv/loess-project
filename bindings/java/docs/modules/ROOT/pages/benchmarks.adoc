= Benchmarks

The Java binding calls the shared `fastLoess` Rust core through JNI. These are CPU reference results from the repository's R comparison harness; they do not measure Java/JNI overhead or Java-specific workloads. This LOESS implementation has no GPU backend.

image::benchmark_comparison.svg[Runtime and speedup comparison of stats::loess with serial and parallel rfastloess across benchmark categories]
