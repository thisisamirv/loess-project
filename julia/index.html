FastLOESS.jl

High-performance LOESS (Locally Estimated Scatterplot Smoothing) for Julia, backed by a Rust library.

See the main documentation and the GitHub repository for full details.

Quick Start

using FastLOESS

x = collect(1.0:0.1:10.0)
y = sin.(x) .+ 0.1 .* randn(length(x))

result = fit(Loess(fraction = 0.3), x, y)
println("Smoothed values: ", result.y)
